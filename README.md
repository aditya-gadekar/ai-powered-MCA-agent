# 🤖 AI-Powered MCA Agent – Academic Assistant & Smart Study Planner

An AI-powered academic assistant designed specifically for MCA students. The project helps students access academic information, understand important topics, organize their studies, and improve their learning experience through an interactive platform.

Built using Python and Streamlit, the application uses a structured CSV-based knowledge base to provide relevant academic information.

## 🚀 Features

* **AI Academic Assistant:** Provides academic assistance for MCA-related subjects.
* **Smart Study Planner:** Helps students organize their study schedules.
* **Subject-Based Learning:** Supports learning across different MCA subjects.
* **Knowledge Base:** Uses structured CSV datasets to retrieve academic information.
* **Interactive Dashboard:** Simple and user-friendly interface.
* **Instant Responses:** Provides relevant answers to student queries.
* **Academic Support:** Helps students with concepts, preparation, and revision.

## 🏗️ Project Architecture

The application follows a simple Python-based architecture:

1. **User Interface:** Streamlit provides an interactive interface.
2. **Input Processing:** Accepts student queries.
3. **Knowledge Base:** Retrieves relevant academic information from CSV datasets.
4. **Response Generation:** Processes available information and provides relevant responses.
5. **Output:** Displays academic assistance through the dashboard.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to Project

```bash
cd AI-Powered-MCA-Agent
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run Application

```bash
streamlit run app.py
```

The application will open in your browser.
